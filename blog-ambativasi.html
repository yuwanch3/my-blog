Membangun Ambativasi:
Aplikasi Belajar Interaktif dengan React Native

9 Agustus 2026 · React Native · Expo SDK 54 · Backend PHP

🤔 Apa itu Ambativasi?

Ambativasi adalah aplikasi belajar interaktif yang saya kembangkan untuk menggabungkan materi, latihan soal, ujian, dan evaluasi dalam satu tempat. Aplikasi ini dirancang sebagai teman belajar yang lengkap — mulai dari materi teks & PDF, kuis interaktif, latihan pelafalan dengan voice recognition, hingga sistem gamifikasi (XP, level, streak, dan leaderboard) agar belajar terasa lebih menyenangkan.

💡 Filosofinya: belajar tidak harus membosankan. Dengan gamifikasi + umpan balik instan, user merasa seperti "bermain" sambil tetap memahami materi secara mendalam.

🛠️ Teknologi yang Digunakan

Frontend dibangun di atas React Native dengan Expo SDK 54, TypeScript, dan Expo Router untuk navigasi berbasis file. Backend memakai PHP + MySQL yang di-host di InfinityFree, dengan autentikasi token Bearer dan proteksi anti-bot slowAES challenge.

  • React Native 0.81 + React 19 + TypeScript 5.9
  • Expo SDK 54, Expo Router 6 (file-based routing)
  • Backend: PHP 8 + MySQL (REST API, JSON)
  • Auth: token Bearer + slowAES challenge
  • Ekstra: speech recognition, PDF viewer, YouTube iframe, push notification

🗂️ Struktur Folder Project

Berikut struktur utama dari project — dipecah berdasarkan tanggung jawab agar mudah dirawat dan diskalakan:

ambativasi-app-test-voice/
├── app/                # Halaman & routing (Expo Router, file-based)
│   ├── (tabs)/         # Tab utama: Home, Chat, Leaderboard, Pengaturan
│   ├── auth/          # Login, Register, Lupa/Reset Password
│   ├── materi/        # Materi: Nihongo, Tajwid, Petrofisika, Chemical EOR
│   ├── ujian/         # Latihan soal & ujian per materi
│   ├── speech/        # Latihan pelafalan (voice recognition)
│   ├── profile.tsx      # Profil user (foto, username)
│   └── statistik/       # Grafik progres belajar
├── components/       # Komponen modular (Navbar, Sidebar, tombol suara)
├── context/         # Global state: Tema, Bahasa, Chat AI
├── src/             # Data materi & logika pendukung
├── assets/          # Gambar, ikon, font, suara
├── config.js           # Base URL API + apiFetch (token & challenge)
└── package.json

Routing berbasis file (Expo Router) membuat setiap file di folder app/ otomatis menjadi halaman — sangat cocok untuk aplikasi yang punya banyak alur (auth → materi → ujian → profil).

🔁 Workflow Pengembangan

1

Perancangan & Struktur

Menentukan alur aplikasi (auth → materi → ujian → profil) dan memetakan setiap screen ke file routing Expo Router.

2

Autentikasi & Backend

REST API PHP + MySQL untuk register/login/lupa password, autentikasi token Bearer, dan proteksi slowAES challenge.

3

Konten & Materi

Menyusun materi, soal, dan ujian per topik; menyimpan data di aplikasi maupun server.

4

Fitur Interaktif

Voice recognition untuk pelafalan, PDF viewer untuk materi, YouTube iframe untuk video pembelajaran.

5

Gamifikasi & Analitik

XP, level, streak, leaderboard, dan grafik statistik untuk memantau progres belajar.

6

Build & Rilis

Build APK lokal (Gradle), upload ke GitHub Releases, dan distribusi sebagai file instalasi Android.
